A point is a swing high if it's the highest value across Left Bars before it and Right Bars after it (fractal detection, confirmed only once both neighbours are known so nothing repaints) — mirror logic for swing lows. Min Swing Move filters noise between consecutive same-type swings. Two same-type swings within EQH/EQL Tolerance are flagged as an equal high/low. The range zone is simply [latest confirmed swing low, latest confirmed swing high] — nothing else defines it. Price clearing that zone's edge by Range Breakout Buffer is a Range Breakout Up or Range Breakout Down.

Each confirmed HH/HL/LH/LL scores Swing Event Weight, routed Call/Put/Ignore per the matrix above. A live Range Breakout scores Range Breakout Weight, plus Liquidity Sweep Weight if it also cleared a marked EQH/EQL level. Every red 5m candle scores Red Candle Weight straight to its own chart's side — fixed, not routed through the matrix. If Call-stream and Put-stream events agree on the same final side, Agreement Bonus is added once. The leading side only becomes Final Bias if it clears Minimum Confidence Threshold — otherwise the payload reports NO_TRADE.

  


  

    
    
    
  


  

    
📘 How This Engine Executes

    


    

      1. Swings → HH / HL / LH / LL (1 Min only)
      
Function: findSwings() then classifyStructure(). Fractal swing test using Left/Right Bars; each new swing compared to the previous same-type swing: higher high → HH, lower high → LH, higher low → HL, lower low → LL. Two same-type swings within EQH/EQL Tolerance are relabelled EQH/EQL — a liquidity pool, not fresh structure. This is the only detection running on the 1 Min charts now.

    


    

      2. Range zone & breakout — the only "event" beyond the raw swings
      
Functions: getZone(), detectRangeBreakout(). The zone is [most recent confirmed swing low, most recent confirmed swing high] — redrawn as a shaded box every time a new swing confirms, no independent lookback or width setting. If the latest closed 1m value clears the zone's high by Range Breakout Buffer, that's a Range Breakout Up; clearing the low is a Range Breakout Down. There is no trend-tracking, no reversal/continuation distinction, no CHoCH — a breakout is just a breakout, either direction, always eligible to score.

    


    

      3. 5 Minute — one fixed rule, not part of the matrix
      
Function: checkRedCandle(). This checks only the most recently closed 5m candle. If it's red on the Call chart, that scores straight to Call. If it's red on the Put chart, that scores straight to Put. Green candles are not evaluated at all — there is nothing to configure here, which is why 5 Min no longer has a settings row in the Interpretation Matrix.

    


    

      4. Interpretation Matrix & scoring
      
HH, HL, LH, LL, Range Breakout Up, and Range Breakout Down are each just a labelled fact from the 1m stream — the matrix is the only place a fact becomes Call/Put/Ignore, per chart. computeScore() sums Swing Event Weight per confirmed swing, Range Breakout Weight (+ Liquidity Sweep Weight if applicable) for an active breakout, and Red Candle Weight for the fixed 5m rule — then gates the leading side against Minimum Confidence Threshold.

    


    

      5. Engine Master Switches — run either timeframe alone
      
Function: toggleEngine(). The 1-Minute Structure Engine and the 5-Minute Red Candle Rule each have their own independent kill switch, separate from the per-chart "Structure" display toggles (which only hide/show swing markers visually and never affect scoring). Turning a kill switch OFF removes that timeframe's contribution to computeScore() entirely for the current cycle — its charts keep rendering for reference, but zero points reach either the CALL or PUT tally from it. Both switches can be off at once, in which case Final Bias is always NO_TRADE since nothing is left to score. The current state of both switches is also written into the Algo Payload as engineActive, so a downstream consumer always knows which timeframe(s) actually produced a given signal.
